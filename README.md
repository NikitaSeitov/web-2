# Машина согласия

Простой статический сайт с Python-сервером для API и хранения ответов.

## Запуск

```bash
cd "c:\Users\Admin\Desktop\Новая папка\Творю\2026\open call\Краснохолмская Машина согласия\web-2"
python server.py
```

После запуска откройте:

```text
http://localhost:8000
```

## Что делает сервер

- обслуживает статические файлы сайта
- сохраняет ответы в `data/responses.json`
- возвращает статистику через `GET /api/statistics`
- принимает ответы через `POST /api/responses`
